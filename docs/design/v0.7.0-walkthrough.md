# Spec 002 Walkthrough — `curfewd v0.7.0` Native Control Plane & Modern `curfewctl` CLI

Implemented and published **`curfewd v0.7.0`** (commit `61a1724`, tag `v0.7.0`), completing the clean-break architecture defined in [002-curfewd-control-plane-and-cli.md](../../docs/specs/002-curfewd-control-plane-and-cli.md) and setting the foundation for Spec 003's Material Design UI.

---

## Changes Made

### 1. Native `curfewd/` Python Package (`+6,000 / -66,213` LOC net cleanup)
- **Models & Parsers:** [parsing.py](../../curfewd/parsing.py) & [models.py](../../curfewd/models.py) — strict Linux username validation, human durations/deltas (`+30m`, `-15m`, `=2h`, `1h30m`), weekday specs (`mon-fri`, `sun-thu`), multi-window minute intervals (`08:00-12:00,15:30-21:00,!21:00-22:00`), and schema-v1 dataclasses (`DaemonConfig`, `UserPolicy`, `TimeWindow`, `PauseState`, `PlayTimePolicy`, `UserAccountingState`, `LockResult`).
- **Atomic JSON Storage & SQLite History:** [storage.py](../../curfewd/storage.py) (`AtomicJsonStore` with `O_NOFOLLOW`, `mkstemp` + `fsync` + `chmod` + `os.replace`) and [history.py](../../curfewd/history.py) (SQLite WAL daily rollups + audit event log + retention pruning).
- **One-Way Legacy Migrator:** [migrate.py](../../curfewd/migrate.py) — converts `/etc/timekpr/timekpr.conf`, `/var/lib/timekpr/config/timekpr.<user>.conf`, and `/var/lib/timekpr/work/<user>.time` cleanly without deleting originals (`--dry-run` supported; auto-invoked on first package install when legacy files exist).
- **Pure Enforcement Engine:**
  - [evaluator.py](../../curfewd/engine/evaluator.py) — deterministic clock-injected policy evaluator with day/week/month rollover, CMOS jump guard, non-destructive `PauseState` auto-expiry, multi-window `next_curfew_at` / `next_allowed_at`, unaccounted windows, and PlayTime support.
  - [screenlock.py](../../curfewd/engine/screenlock.py) — ported Spec 001 3-layer multi-DE + X11 grab-release enforcer returning structured `LockResult` telemetry while keeping privilege-dropped `(uid, gid, extra_groups=[])` execution.
  - [sessions.py](../../curfewd/engine/sessions.py), [playtime.py](../../curfewd/engine/playtime.py), and [doctor.py](../../curfewd/engine/doctor.py) (`curfewctl doctor [--fix]` including built-in root `dconf` lock installation).

### 2. `org.curfewd.Daemon1` D-Bus Service, Polkit & `CurfewClient` SDK
- [polkit.py](../../curfewd/dbus/polkit.py) & [org.curfewd.policy](../../resource/server/polkit/org.curfewd.policy) — in-daemon Polkit authorization (`org.curfewd.read`, `org.curfewd.manage`, `org.curfewd.lock`) so Spec 003's Material Design UI runs completely unprivileged (`root` and `curfewd` group bypass for headless CLI/SSH).
- [service.py](../../curfewd/dbus/service.py) — exports `Admin`, `Client` (strictly bound to `GetConnectionUnixUser(sender)` + CSPRNG single-use `hmac.compare_digest` nonces), and live `Events` signals on `/org/curfewd/Daemon1`.
- [client.py](../../curfewd/dbus/client.py) — typed `CurfewClient` SDK with `follow_name_owner_changes=True`, `introspect=False`, and typed exceptions (`DaemonUnavailableError`, `PermissionDeniedError`, `UserNotFoundError`, `ValidationError`).
- [daemon.py](../../curfewd/daemon.py) — daemon entrypoint with `O_NOFOLLOW` lock-before-truncate PID file in `/run/curfewd/curfewd.pid`.

### 3. Modern `curfewctl` CLI & Auto-Reconnecting `curfewd-tray`
- [main.py](../../curfewd/cli/main.py) — full subcommand CLI (`status`, `users`, `grant`, `limit`, `window`, `lockout`, `pause`, `resume`, `lock`, `history`, `playtime`, `config`, `doctor`, `migrate-timekpr`) with global `--json` support, natural negative deltas (`curfewctl grant alice -15m --json`), and standardized exit codes (`0`..`4`).
- [app.py](../../curfewd/tray/app.py) — lean, Glade-free desktop companion using `watch_name_owner` (`NameOwnerChanged`) to auto-reconnect seamlessly after daemon restarts/upgrades.

### 4. Hardened Systemd Unit, Packaging & Legacy Removal
- Added [curfewd.service](../../resource/server/systemd/curfewd.service) (`ProtectSystem=strict`, `ProtectHome=read-only`, `PrivateTmp=yes`, `ProtectKernelTunables/Modules/ControlGroups`, `MemoryMax=256M`, `TasksMax=64`, `RestartSec=5`), [org.curfewd.Daemon1.conf](../../resource/server/dbus/org.curfewd.Daemon1.conf), and [curfewd-tray.desktop](../../resource/launchers/curfewd-tray.desktop).
- Removed legacy `common/`, `client/`, `server/`, `bin/timekpr*`, and ~9,850 LOC of GTK3/Glade UI; updated [debian/control](../../debian/control), [debian/install](../../debian/install), [debian/postinst](../../debian/postinst), [debian/postrm](../../debian/postrm), [debian/changelog](../../debian/changelog), [README.md](../../README.md), [SECURITY.md](../../SECURITY.md), [AGENTS.md](../../AGENTS.md), and GitHub Actions workflows.
